BlossomPricer Discord Bot

Introducing the new BlossomPricer Discord Bot, which allows you to access prices in a faster and simpler way!

Click here to add the bot to your Discord account or server!
Adding the bot to your account allows you to use it in DMs or any server that allows external applications.

If you don't want to add the bot to your "My Apps" collection on Discord, a separate Discord server for using the bot will be available soon! Currently, the bot only supports looking up the current price of an item. Price history and more will be coming soon!
